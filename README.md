# PRODIGY_GA_03 — Text Generation with Markov Chains

Task 3 of the Prodigy InfoTech Generative AI internship.

- Builds a simple word-level Markov chain from a sample text.
- Every word maps to the words that follow it; the generator picks the next word at random from that list.
- Pure Python, no external libraries.

**Tech:** Python

## Run

```bash
python Task-3.py
```

Replace the `text` variable in `Task-3.py` with a longer text to get more varied output.
